# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release of YouTube Downloader
- GTK 4 graphical user interface
- Support for multiple video quality options (1080p, 720p, 480p)
- Audio extraction to MP3 format
- Playlist download support
- Real-time download progress tracking
- Video information display (title, uploader, duration)
- Custom download folder selection
- Threaded download operations for non-blocking UI
- Comprehensive README and documentation

### Features
- Download YouTube videos in multiple qualities
- Extract audio as MP3
- Download entire playlists
- Modern GTK 4 interface
- Progress bar with percentage display
- Video metadata display before download
