# Contributing to YouTube Downloader

Thank you for your interest in contributing! We welcome contributions from everyone.

## Getting Started

1. **Fork the Repository**: Click the fork button on GitHub
2. **Clone Your Fork**: 
   ```bash
   git clone https://github.com/yourusername/youtube-downloader.git
   cd youtube-downloader
   ```
3. **Create a Branch**: 
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Install Development Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## Development Guidelines

- Write clear, descriptive commit messages
- Test your changes thoroughly before submitting
- Follow PEP 8 style guidelines for Python code
- Update documentation if your changes affect it

## Submitting Changes

1. **Push Your Changes**:
   ```bash
   git push origin feature/your-feature-name
   ```
2. **Create a Pull Request**: Go to GitHub and create a PR with:
   - Clear title describing the changes
   - Detailed description of what was changed and why
   - Reference any related issues

## Reporting Bugs

When reporting bugs, please include:
- Your operating system and version
- Python version
- GTK version
- Steps to reproduce the issue
- Expected vs actual behavior
- Any error messages or logs

## Feature Requests

Feel free to suggest new features! Please describe:
- What the feature should do
- Why it would be useful
- Any potential implementation ideas

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help others in the community

## Questions?

Open an issue with the `question` label or start a discussion if you need clarification.

Thank you for contributing! 🙌
